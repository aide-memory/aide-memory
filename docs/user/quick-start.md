# Quick Start

**Canonical version: https://aide-memory.dev/docs/quick-start**

Install to first recall in 2 minutes:

```bash
npm install -g aide-memory
aide-memory init
aide-memory remember "API responses must use camelCase keys" --layer guidelines
aide-memory recall src/
```

The website page covers prerequisites, the full directory layout, the six hooks, editor-specific setup, common commands, and configuration. See [aide-memory.dev/docs/quick-start](https://aide-memory.dev/docs/quick-start).
