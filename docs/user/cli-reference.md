# CLI Reference

**Canonical version: https://aide-memory.dev/docs/cli-reference**

13 CLI commands: `init`, `recall`, `remember`, `update`, `forget`, `search`, `list`, `stats`, `recall-log`, `config`, `sync` (`import` / `export`), `migrate`, `cleanup`.

```bash
aide-memory <command> [arguments] [flags]
```

For each command's flags, examples, output shapes, and error states, see [aide-memory.dev/docs/cli-reference](https://aide-memory.dev/docs/cli-reference).
