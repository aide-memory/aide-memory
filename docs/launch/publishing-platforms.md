# Publishing platforms reference

Where to publish the aide-memory launch. Ordered by priority.

## High priority (launch week)

| Platform | What to post | Timing | Notes |
|---|---|---|---|
| **aide-memory.dev/blog** | Full blog post (canonical) | First | SEO authority, canonical URL for cross-posts |
| **LinkedIn** | LinkedIn version (linkedin-post.md) | Same day | Personal network, attach homepage screenshot |
| **dev.to** | Cross-post blog with canonical URL | Same day | Large dev community, markdown native, free |
| **Hacker News** | "Show HN: aide-memory" link to blog | Tue-Thu 9-11 AM PST | Technical credibility. Lead with problem, not product. Add backstory comment. |
| **Reddit** (r/ClaudeAI, r/cursor, r/programming) | Link post to blog | Same day | Lead with the problem. Don't self-promote too hard. |

## Medium priority (launch week or shortly after)

| Platform | What to post | Notes |
|---|---|---|
| **Product Hunt** | Full launch page | Tue-Thu midnight PST. Needs tagline, screenshots, maker comment. Plan to be active 24h. |
| **Hashnode** | Cross-post blog with canonical URL | Free, strong SEO, newsletter built in |
| **X/Twitter** | Short thread or link | Thread format with key points + link to blog |

## Lower priority (post-launch)

| Platform | What to post | Notes |
|---|---|---|
| **Console.dev** | Email david@console.dev | Curated newsletter, ~1M+ subscribers. Selective editorial process. |
| **TLDR Newsletter** | No direct submission | Curated. More likely to pick up organically if HN/PH gain traction. |
| **The Changelog** | Podcast pitch | Interview format. Better after some traction. |
| **Medium** | Cross-post (optional) | Paywall limits reach. Use "friend links" if you do post. |

## Timing

Best launch window: Tuesday-Thursday mornings US time.

1. Publish blog on aide-memory.dev
2. Post LinkedIn (same day)
3. Cross-post to dev.to (same day, with canonical URL to aide-memory.dev/blog/launch)
4. Submit to Hacker News (same day, 9-11 AM PST)
5. Post to Reddit (same day)
6. Product Hunt launch (next day or same week)
7. Email Console.dev after launch day traction
