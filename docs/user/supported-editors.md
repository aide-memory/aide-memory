# Supported Editors

**Canonical version: https://aide-memory.dev/docs/supported-editors**

aide-memory is editor-agnostic at the core. Adapter status today:

| Editor | Status |
|---|---|
| **Claude Code** | Reference adapter, every capability works as designed |
| **Cursor** | Full hook + MCP wiring; some capabilities tracked against upstream Cursor platform work |
| **Windsurf** | Rule template only; full adapter is post-launch work |
| **Codex** | Rule template only; full adapter is post-launch work |
| **Copilot** | Rule template only; full adapter is post-launch work |

For the full capability matrix (hard-block on Read/Edit, soft nudges, session-start injection, correction detection, etc.) and per-editor UX, see [aide-memory.dev/docs/supported-editors](https://aide-memory.dev/docs/supported-editors).
